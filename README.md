# نومبو ۲ (Numbo-2)

کراولر سبک، پایدار و قابل اجرای مداوم برای استخراج اطلاعات تماس عمومی از وب‌سایت‌ها.

طراحی شده برای اجرا روی هاست لینوکس، استخراج شماره تماس (به‌خصوص فرمت‌های ایرانی)، ایمیل، آدرس و دسته‌بندی نتایج برای استفاده بعدی.

## ویژگی‌های اصلی

- اجرای مداوم تا زمانی که خودت متوقفش کنی
- استخراج شماره موبایل و ثابت ایرانی + بین‌المللی
- استخراج ایمیل، نام کسب‌وکار، آدرس تقریبی
- حذف تکراری خودکار
- دسته‌بندی ساده بر اساس کلیدواژه و شهر
- ذخیره در SQLite + خروجی CSV/Excel
- احترام به robots.txt و Rate Limit
- آماده اجرا با یک دستور

## پیش‌نیاز

- Python 3.10 یا بالاتر
- لینوکس (Ubuntu / Debian / CentOS و ...)

## نصب سریع

```bash
git clone https://github.com/samanramezani1377-hub/numbo-2.git
cd numbo-2
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## نحوه اجرا (مداوم)

1. لیست دامنه‌ها یا URLهای اولیه را در فایل `seeds.txt` قرار بده (هر خط یک دامنه یا URL).

2. اجرا:

```bash
python run.py
```

کراولر شروع به کار می‌کند و تا زمانی که با `Ctrl+C` یا سیگنال SIGTERM متوقفش نکنی، ادامه می‌دهد.

برای اجرا در پس‌زمینه (recommended روی سرور):

```bash
nohup python run.py > numbo.log 2>&1 &
```

یا با systemd (فایل سرویس در پوشه `deploy/` قرار دارد).

## خروجی‌ها

- دیتابیس: `data/numbo.db`
- خروجی CSV: `data/export_contacts.csv` (با دستور `python export.py`)
