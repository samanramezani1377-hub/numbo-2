# نومبو ۲ (Numbo-2)

کراولر سبک + **رابط کاربری وب کامل** برای استخراج اطلاعات تماس و تشخیص تکنولوژی سایت‌ها.

## ویژگی‌های اصلی

- رابط کاربری وب فارسی (داشبورد، نتایج، لاگ، کنترل شروع/توقف)
- اجرای مداوم کراولر
- استخراج شماره موبایل و ثابت ایرانی + ایمیل + شبکه‌های اجتماعی
- تشخیص تکنولوژی (WordPress، WooCommerce، Shopify، Laravel، Next.js و ...)
- فیلتر قابل تنظیم دامنه (پیش‌فرض فقط `.ir`)
- حذف تکراری + دسته‌بندی + تشخیص شهر
- خروجی Excel / CSV
- آماده اجرا روی لینوکس

## نصب

```bash
git clone https://github.com/samanramezani1377-hub/numbo-2.git
cd numbo-2
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## راه‌اندازی رابط کاربری (پیشنهادی)

```bash
python start_ui.py
```

سپس در مرورگر باز کن:

```
http://IP-سرور:8080
```

از داخل پنل می‌تونی:

- کراولر را **شروع** یا **توقف** کنی
- لیست دامنه‌ها (seeds) را ویرایش کنی
- فیلتر TLD (مثلاً فقط `.ir`) را تغییر بدهی
- نتایج را ببینی و فیلتر کنی (بر اساس تکنولوژی، شهر، شماره و ...)
- لاگ زنده ببینی
- خروجی Excel دانلود کنی

## اجرای مستقیم کراولر (بدون پنل)

```bash
python run.py
```

## خروجی دستی

```bash
python export.py
```
